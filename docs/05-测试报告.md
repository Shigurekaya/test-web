## 2. 测试范围与策略

**范围内**

| 范围 | 说明 |
|------|------|
| 鉴权与会话 | 登录/退出、角色菜单、未登录重定向、登录回跳安全 |
| 权限隔离 | 公开/内部/机密三级 × 管理员/同部门/异部门/作者 |
| 检索与问答 | 文档切分、分词、打分权重、Top-K、来源去重、无命中降级 |
| 密级防泄漏 | 列表、检索、问答共用同一套可见性判定；异部门机密不得进入来源 |
| 防爆破 | 阈值、窗口过期、锁定后正确密码仍拒绝、成功清零 |
| 审计 | 登录、浏览、问答、写操作，**以及登录失败** |
| 运维 | 健康检查、启停脚本、全新库自建、演示故事线 |
| 统计口径 | 关于页数字跟随用户可见范围，不泄露机密规模 |

**范围外（本期不测）**

- 真实大模型调用的稳定性与计费；
- 千人并发压测（SR 中已列为非硬性指标）；
- 跨浏览器像素级 UI 回归；
- 多进程部署下的登录限流（限流为进程内实现，已在文档中说明）。

**策略**：手工覆盖演示故事线；自动化按「安全边界 → 检索算法 → 系统主路径」分层，
作为每次改动后的回归底线。全部用例运行在独立临时数据库上，
不读写 `instance/knowledge.db`，因此可反复执行且互不影响。

## 4. 测试过程中发现并已修复的缺陷

| 编号 | 描述 | 级别 | 处理 |
|------|------|------|------|
| DEF-01 | 测试套件使用默认配置创建应用，把演示文档、审计与问答记录写进 `instance/knowledge.db`（单次运行文档数从 33 涨到 36，审计记录超过 500 条） | 高 | 已修复：新增测试配置使用内存库，并为每个用例准备独立夹具与回滚；修复后数据库在测试前后完全不变 |
| DEF-02 | jieba 默认词典不含「年假」，分词后两个单字被长度过滤丢弃，分词结果为空集，标题/标签/关键词加权全部失效（「年假」正是交付文档中的示例检索词） | 高 | 已修复：补充领域词表并加相邻二字组兜底；「年假」现已正确分词且目标文档排在首位 |
| DEF-03 | 在线 PlantUML 服务无中文字体，10 张 UML 图的中文标签渲染为空白方框 | 高 | 已修复：改用本地 PlantUML + Noto Sans SC 字体离线渲染，10 张图全部正常 |
| DEF-04 | 种子数据顺序哈希 22 个账号密码耗时约 18.3 s（scrypt 为 CPU 密集型），冷启动约 22.5 s | 中 | 已优化：线程池并发预计算（scrypt 会释放 GIL），冷启动降到约 10.3 s，测试套件从约 69 s 降到约 59 s |
| DEF-05 | 登录无次数限制，可被脚本爆破；且审计只记录登录成功，看不到失败尝试 | 中 | 已修复：新增 IP 级滑动窗口限流（阈值走配置），锁定期间正确密码同样拒绝；失败登录写入审计 |
| DEF-06 | 关于页对所有人展示全库文档数与片段数，可据此推断机密材料规模 | 中 | 已修复：统计改为跟随当前用户可见范围，并在页面标注口径 |
| DEF-07 | 代码存在未使用导入、导入排序与 `zip()` 未指定 `strict=` 等静态检查问题 | 低 | 已修复：`ruff` 检查全部通过 |

## 5. 残留风险与已知限制

1. **本地摘要模式**表达偏「片段拼接」，未配置大模型时属预期行为（SR-QA-003）。  
2. **同义改写召回**：极端换说法可能打分不足，依赖分词与演示语料覆盖。  
3. **登录限流为进程内实现**：适合单机/单进程演示；多进程或多机部署需换成
   Redis 等共享存储，代码中已注明。  
4. **SQLite**：适合本机/局域网演示；高并发需换库并补连接池。  
5. **未做覆盖率度量**：本机环境下 `pytest-cov` 的 C tracer 会与 jieba 首次导入死锁
   （已单独验证：`coverage.start()` 后 `import jieba` 不返回），
   因此 CI 未接入 `--cov`，避免构建挂死。  
6. **静态展示站**（`npm run pages:build` + `scripts/sync_pages_demo.mjs`）：使用浏览器内 Mock API，无真实写库能力，仅用于页面预览，不属于 Flask 运行时缺陷。

## 6. 测试结论

系统满足《用户需求说明书》与《系统需求说明书》中的高优先级要求：
鉴权与角色菜单、三级密级隔离（含同部门与作者判定）、检索与带来源问答、
知识图谱、收藏、审计（含失败登录）、防爆破、健康检查与全新库自建均可演示。

99 条自动化用例全部通过，静态检查无告警；测试不触碰演示数据，可反复执行。

**建议演示顺序**：`admin` 全貌 → 搜「年假」→ 问答「年假几天」→ 关系图 →
换 `hr` / `it` 对比机密文档 → 审计日志（含登录失败）→ 连续输错密码触发锁定。
