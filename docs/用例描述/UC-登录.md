# 用例描述：登录系统

| 项 | 内容 |
|----|------|
| 用例名称 | 登录系统 |
| 用例编号 | UC-AUTH-01 |
| 参与者 | 管理员、普通员工 |
| 前置条件 | 系统已启动；用户拥有合法账号 |
| 后置条件 | 建立登录会话；写入审计日志 |

## 基本事件流

1. 用户打开登录页  
2. 输入用户名、密码并提交  
3. 系统校验凭证  
4. 校验成功，跳转工作台  

## 备选事件流

3a. 用户名不存在或密码错误 → 提示「用户名或密码错误」，停留登录页  

## 业务规则

- 密码以哈希形式存储与比对  
- 登录成功记录 `audit_logs.action=login`
