# 智慧企业知识财富库系统——系统设计说明（精简版）

| 项目 | 内容 |
|---|---|
| 架构风格 | 前后端分离、单体后端、分层服务 |
| 前端 | Vue 3 + Vite + Vue Router + ECharts |
| 后端 | Flask 3 + Flask-Login + SQLAlchemy |
| 数据库 | SQLite（可通过 DATABASE_URL 切换） |

## 1. 总体架构

```text
浏览器
  └─ Vue 3 SPA
      ├─ 页面与组件
      ├─ 路由与权限守卫
      └─ REST API 客户端
              │
          Flask REST API
              ├─ 认证与权限
              ├─ 文档/分类/审计服务
              ├─ RAG 检索与问答服务
              └─ 知识图谱同步服务
                      │
                 SQLAlchemy
                      │
                   SQLite
```

AI 服务通过后端调用兼容 OpenAI 协议的接口。真实密钥只保存在服务端 `.env` 或部署平台 Secrets 中，不进入源码、构建产物和静态页面。

## 2. 功能模块

| 模块 | 主要职责 |
|---|---|
| 认证模块 | 登录、退出、会话、密码校验、登录限流 |
| 文档模块 | 文档 CRUD、分类、标签、版本、状态、收藏 |
| 权限模块 | 管理员/员工角色；公开/内部/机密访问控制 |
| 检索模块 | 标题、摘要、正文、标签检索与筛选分页 |
| RAG 模块 | 文本切分、关键词提取、相关度排序、回答与来源 |
| 图谱模块 | 文档、部门、分类、关键词节点及关系同步 |
| 工作台模块 | 统计指标、图表、最近文档、问答和审计动态 |
| 管理模块 | 用户目录、分类维护、审计日志 |
| 静态演示 | Cloudflare Pages 展示页面与 Mock 数据 |

## 3. 核心数据模型

| 数据表 | 关键字段 | 作用 |
|---|---|---|
| users | username, password_hash, role, department | 用户与权限身份 |
| documents | title, content, visibility, department, status | 知识文档主体 |
| categories | name, description | 文档分类 |
| knowledge_chunks | document_id, content, keywords | RAG 检索片段 |
| favorites | user_id, document_id | 用户收藏关系 |
| graph_nodes | name, node_type, document_id | 图谱节点 |
| graph_edges | source_id, target_id, relation | 图谱关系 |
| qa_history | user_id, question, answer, sources, mode | 问答历史与来源 |
| audit_logs | user_id, action, detail, created_at | 审计追踪 |

主要关系：用户一对多文档和问答；文档一对多知识片段；文档与分类、作者为多对一关系；图谱节点通过有向边关联。

## 4. RAG 问答流程

1. 根据当前用户过滤可见且已发布的文档。
2. 加载对应知识片段，使用 jieba 分词并补充领域词典。
3. 综合关键词、标题、标签和短语重合度计算相关度。
4. 取 Top-K 片段，同一文档限制片段数量。
5. 配置大模型时生成回答；失败或无配置时生成本地检索摘要。
6. 保存问答历史、来源和模式，并写入审计日志。
7. 前端展示回答、来源文档和相关片段。

## 5. 权限与安全设计

- 所有业务接口先认证，再判断角色或文档访问权限。
- 机密文档仅作者或同部门用户可访问，检索阶段即过滤片段。
- 密码使用哈希保存，登录失败按 IP 限流。
- API 使用统一 JSON 错误结构；未登录返回 401，越权返回 403。
- API 密钥通过环境变量注入；`.env` 加入 `.gitignore`。
- 静态站如需真实 AI，必须通过 Cloudflare Function 等服务端代理，严禁把密钥写入前端。

## 6. 接口分组

| 分组 | 示例 |
|---|---|
| 会话 | `/api/auth/login`、`/api/auth/logout`、`/api/auth/session` |
| 文档 | `/api/documents`、`/api/documents/{id}`、`/api/documents/favorites` |
| 问答 | `/api/qa`、`/api/qa/ask`、`/api/qa/history/{id}` |
| 图谱 | `/api/graph`、`/api/graph/nodes`、`/api/graph/edges` |
| 管理 | `/api/admin/users`、`/api/admin/audits` |
| 系统 | `/api/meta`、`/api/about`、`/api/health` |

## 7. 部署设计

- **主系统**：Flask 提供 REST API 和 `/ui/` 生产前端。
- **开发环境**：Flask + Vite，Vite 将 `/api` 代理到后端。
- **静态展示**：Cloudflare Pages 使用 Mock API，不依赖数据库和真实密钥。
- **真实 AI 演示**：静态页通过 Pages Function 调用后端模型接口，密钥保存在平台环境变量中。

## 8. 设计边界

当前为课程级单机系统，不包含微服务、分布式数据库、消息队列、向量数据库和大数据计算平台。

## 9. 后续优化设计

### 9.1 当前主要瓶颈

| 位置 | 现状 | 优化方向 |
|---|---|---|
| 检索 | 每次加载可见知识片段并在 Python 内计算相关度 | 增加 FTS 索引、向量索引和缓存，采用混合检索与重排 |
| 文档 | 版本号仅为字段，没有历史快照；上传目录尚未形成完整入库流程 | 增加文档版本表、附件表和异步解析任务 |
| 数据层 | 使用 SQLite 和 `db.create_all()` 建表 | 引入 Alembic 迁移；数据增长后切换 PostgreSQL |
| 安全 | 会话接口缺少显式 CSRF 令牌，登录限流为进程内状态 | 增加 CSRF、持久化限流和更细粒度 RBAC |
| 前端 | ECharts 形成较大异步包，复杂页面状态分散 | 按页面拆包、缓存图表实例、统一错误与加载状态 |
| 运维 | 审计、问答和文档同步均在请求内完成 | 增加任务队列、结构化日志、指标、备份与恢复演练 |

### 9.2 演进架构

```text
Vue 3 SPA
  ├─ 权限路由与统一交互状态
  └─ REST API
        ├─ 认证 / 文档 / 审计
        ├─ 混合检索服务（关键词 + 向量 + 重排）
        ├─ RAG 编排与反馈
        └─ 异步任务（解析、索引、通知、导出）
                 │
        PostgreSQL / 全文索引 / 向量索引
                 │
          对象存储（附件与原文）
```

### 9.3 优先改造

1. **检索质量**：查询改写、关键词与向量双路召回、重排、无答案判定和引用定位。
2. **知识生命周期**：附件解析、版本快照、审核发布、纠错反馈、过期提醒和归档。
3. **知识运营**：热搜、零结果、未解决问题、引用排行和部门贡献分析。
4. **工程可靠性**：数据库迁移、后台任务、缓存、CSRF、限流持久化、日志指标和备份恢复。
5. **前端性能**：图表按需加载、路由级代码分割、列表虚拟化和可访问性检查。
6. **部署安全**：静态站仅调用同源代理接口，模型密钥由服务端或平台 Secret 注入。
