# 企业知识库管理系统

> 综合项目实践 · 大作业
> 技术：Python + Flask + SQLite

## 运行方法

```powershell
pip install -r requirements.txt
python run.py
# 浏览器打开 http://127.0.0.1:5000 ，账号 admin / admin123
```

或直接用脚本：`.\start.ps1` 启动，`.\stop.ps1` 停止，`.\run_tests.ps1` 跑测试。

## 功能

- 用户登录（管理员 / 普通员工）
- 知识文档的增删改查、分类、按关键词搜索
- 文档分公开、内部、机密三级，机密文档只有同部门和管理员能看
- 简单的站内问答：按关键词检索相关文档并给出摘要
- 简单的关系图展示：文档—部门—分类的关系
- 收藏、操作日志
