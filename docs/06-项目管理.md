# 项目管理文档

**项目名称**：智慧企业知识财富库系统  
**文档版本**：V1.3  
**日期**：2026-10-17

---

## 1. 项目目标

完成「智慧企业知识财富库系统」从需求、设计、实现到测试的全过程，交付：

- 可运行的 Flask + SQLite Web 应用；  
- 完整文档包（竞品 / 用户需求 / 系统需求 / 设计 / 测试 / 本项目管理）；  
- PlantUML 图集与自动化冒烟测试。

成功标准：本机可启动；主演示路径（登录 → 检索 → 问答 → 图谱 → 机密对比）可复现；`run_tests.ps1` 通过。

## 2. 范围管理

**In Scope**

| 模块 | 说明 |
|------|------|
| 认证授权 | 登录会话、角色菜单、密级鉴权 |
| 知识文档 | 分类、检索、详情、编辑、发布 |
| 站内问答 | 分词检索 + 摘要 / 可选 LLM + 来源与历史 |
| 知识关系图 | 自动同步 + 可视化 + 管理员维护 |
| 收藏与审计 | 个人收藏、关键操作日志（含登录失败） |
| 登录安全 | IP 级滑动窗口防爆破、失败计数与锁定 |
| 运维支撑 | 健康检查、关于页、启停与测试脚本、文档、CI、UML 本地渲染 |

**Out of Scope**

- 真实向量数据库与模型微调 / 生产级 LLM 运维  
- 移动端原生 App  
- AD/LDAP、复杂审批流、多租户 SaaS、在线协同编辑  

变更原则：新增能力须先改系统需求与范围表，再动代码，避免范围膨胀。

## 5. 风险管理

| 风险 | 影响 | 概率 | 应对 |
|------|------|------|------|
| 外网大模型不可用 | 问答演示失败 | 中 | 默认本地摘要；LLM 为增强项 |
| 功能同质化 | 差异点不突出 | 中 | 强化权限 + 来源问答 + 图谱 |
| 范围膨胀 | 做不完 | 高 | 冻结 6 模块；Out of Scope 明示 |
| 环境不一致 | 无法复现 | 中 | 项目内 venv + 启停/测试脚本 |

## 6. 质量保证

1. **分层**：Blueprint / services / models 分离，关键算法不进模板。  
2. **追踪**：用户需求 `UR-*` → 系统需求 `SR-*` → 路由/服务 → 测试编号。  
3. **回归**：改动后执行 `.\run_tests.ps1`，并手工走一遍「年假问答 + 机密对比」。  
4. **文档一致**：文案仅描述本项目能力，避免与实现脱节的夸大表述。

## 7. 工程化与质量保障

本项目除业务功能外，同时补齐了常规工程实践，作为可维护性的直接证据：

| 项 | 做法 |
|----|------|
| 依赖管理 | `requirements.txt`（运行）/ `requirements-dev.txt`（开发测试）/ `pyproject.toml`（统一声明项目元信息） |
| 配置分层 | `app/config.py` 提供默认 / 测试 / 生产三套配置，敏感项与阈值一律走环境变量，不硬编码散落 |
| 静态检查 | `ruff`（E/F/W/I/B/UP 规则集），CI 中作为独立步骤；当前无告警 |
| 自动化测试 | 99 条用例分四个文件，覆盖权限矩阵、检索算法、防爆破、失败审计、全新库自建 |
| 测试隔离 | 测试使用独立临时数据库，**不读写演示库**，可反复执行且互不影响 |
| 持续集成 | GitHub Actions：依赖安装 → ruff → pytest → 全新库启动校验 |
| 文档渲染 | UML 图由脚本本地离线渲染（含中文字体），保证交付图中中文可读 |
| 性能 | 种子数据密码哈希改为线程池并发，冷启动从约 22.5 s 降至约 10.3 s |

已知工程限制：

- 登录限流为**进程内**实现，适合单机 / 单进程演示；多进程部署需更换为共享存储（代码已注明）。  
- 本机环境下 `pytest-cov` 的 C tracer 与 jieba 首次导入存在死锁，因此 CI 未接入覆盖率统计，
  以免构建挂死；该问题已单独复现并记录在测试报告「残留风险」中。
