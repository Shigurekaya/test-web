# 用例模型索引

本目录保存智慧企业知识财富库系统的用例模型。正式总览以
[`00-用例模型总览.md`](./00-用例模型总览.md) 为准，包含：

- 参与者定义与管理员/员工泛化关系；
- 17 个用户目标用例和 3 个共享/扩展用例；
- 系统用例图与用例关系图；
- 每个用例的前置条件、基本流、备选流、后置条件和业务规则；
- 需求、REST API 与自动化测试之间的追踪关系。

## 与旧版模型的差异

旧版用例图只有 11 个较粗的用例点，并把“管理知识文档”作为一个笼统用例。
新版按用户目标拆分为发布/更新、删除、检索和查看详情，同时补充工作台、问答历史、
分类新增、图谱新增、用户目录、系统信息和健康检查，并明确：

1. 管理员继承普通员工能力；
2. 智能问答包含权限内检索，模型增强是可选扩展；
3. 发布/更新文档包含索引和图谱同步；
4. 检索、详情、收藏、图谱和问答共同依赖文档权限校验；
5. 未实现的附件流程、用户增删改和图谱编辑删除不进入当前用例模型。
