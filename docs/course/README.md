# 课程作业正式文档

本目录存放《智慧企业知识财富库系统》V2.0 的课程作业正式文档源文件。`scripts/build_course_docs.py` 会将其转换为统一排版的 Word 文档，输出到项目根目录的 `deliverables/`。

| 顺序 | 文档 | 主要内容 | 对应图 |
|---|---|---|---|
| 01 | [项目开发计划](./01-项目开发计划.md) | 范围、WBS、单人角色、12 周计划、风险、验收 | 里程碑表 |
| 02 | [软件需求规格说明书](./02-软件需求规格说明书.md) | 33 项功能需求、权限矩阵、用例、非功能与追踪 | 用例图 |
| 03 | [软件设计规格说明书](./03-软件设计规格说明书.md) | 前后端架构、模块、数据库、API、安全、部署 | UML 与架构图 |
| 04 | [项目测试计划](./04-项目测试计划.md) | 策略、级别、环境、准入准出、缺陷、风险 | 测试流程图 |
| 05 | [测试用例说明书](./05-测试用例说明书.md) | 73 条测试用例、执行模板、追踪矩阵 | 用例与自动化映射 |
| 06 | [项目总结](./06-项目总结.md) | 计划与实际、成果、质量、问题、改进、自评 | 交付清单 |
| 07 | [个人项目小结与考核材料](./07-个人项目小结与考核材料.md) | 个人分工与学校要求的 5 项考核材料 | 用例、原型、时序、类、ER |
| 08 | [REST API 接口设计说明书](./08-REST-API接口设计说明书.md) | 认证、错误码、接口、请求响应与权限 | 接口表 |

## 学校要求的 5 项个人材料

1. 用例图与用例规格说明：见文档 07 第 2 章及 `docs/uml/01-用例图.puml`。
2. 页面原型设计及说明：见文档 07 第 3 章及 `docs/screenshots/`。
3. 用例实现顺序（时序）图及说明：见文档 07 第 4 章及 `docs/uml/02-登录时序图.puml`、`03-RAG问答时序图.puml`。
4. 系统/模块类图及说明：见文档 07 第 5 章及 `docs/uml/06-类图.puml`。
5. 数据库实体类图与 E-R 图及说明：见文档 07 第 6 章及 `docs/uml/07-ER图.puml`。

## 生成 Word

```powershell
.\.venv\Scripts\python.exe scripts\build_course_docs.py
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\update_word_fields.ps1
```
