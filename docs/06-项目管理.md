# 项目管理文档

**项目名称**：智慧企业知识财富库系统  
**文档版本**：V1.0  
**日期**：2026-09-15

---

## 1. 项目目标

完成选题「智慧企业知识财富库系统」的软件工程全过程：需求 → UML → 实现 → 测试，交付可运行系统与完整文档。

## 2. 范围管理

**In Scope**

- 6 大业务模块（权限、文档、检索、RAG、图谱、收藏审计）  
- Flask MVC 实现与演示数据  
- 全套文档与 PlantUML  

**Out of Scope**

- 真实向量数据库与模型微调  
- 移动端原生 App  
- 复杂审批流 / 多租户 SaaS

## 5. 风险管理

| 风险 | 影响 | 应对 |
|------|------|------|
| RAG 依赖外网 API | 演示失败 | 默认本地摘要模式 |
| 选题撞车 | 评分差异化不足 | 强化权限+图谱+来源问答 |
| 范围膨胀 | 做不完 | 冻结为 6 模块 |
| 环境不一致 | 无法运行 | 项目内 venv + 启停脚本 |

## 6. 质量保证

- 代码分层清晰，关键路径有自动化测试  
- 文档与实现双向追踪（需求编号 → 路由/服务）  
- 提交前执行 `run_tests.ps1` 与 5 分钟验收路径  

## 7. 配置与交付

- 源码与文档统一置于 `大作业/`  
- 入口：`00-提交说明.md`  
- 运行产物 `instance/*.db`、日志可不纳入评分关注点
