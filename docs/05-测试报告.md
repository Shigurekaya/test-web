## 2. 测试范围与策略

**范围内**

- 登录鉴权与会话  
- 文档列表检索、详情、密级隔离  
- 站内问答（本地摘要模式）与历史  
- 关系图 JSON 与页面可达  
- 收藏、审计、健康检查、新建文档后可检索  

**范围外（本期不测）**

- 真实 OpenAI 调用稳定性与计费  
- 千人并发压测  
- 跨浏览器像素级 UI 回归  

**策略**：手工覆盖演示故事线；自动化覆盖主路径冒烟，作为每次改动后的回归底线。

## 5. 残留风险与已知限制

1. **本地摘要模式**表达偏「片段拼接」，未配置大模型时属预期行为（SR-QA-003）。  
2. **同义改写召回**：极端换说法可能打分不足，依赖分词与演示语料覆盖。  
3. **SQLite**：适合本机/局域网演示；高并发需换库并补连接池。  
4. **静态展示站**：无真实写库；POST/管理写入会被前端拦截提示。

## 6. 测试结论

系统满足用户需求与系统需求中的**高优先级**项：鉴权、检索、问答带来源、图谱、机密隔离、审计均可演示，自动化冒烟覆盖主路径，**具备联调与功能演示条件**。

建议演示顺序：admin 全貌 → 问答「年假」→ 关系图 → 换 hr / it 对比机密文档。
