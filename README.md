# 智慧企业知识财富库

> 企业内部知识管理 Web 应用  
> 技术：Python + Flask + SQLite

## 运行方法

```powershell
pip install -r requirements.txt
python run.py
# 浏览器打开 http://127.0.0.1:5000 ，账号 admin / admin123
```

或：`.\start.ps1` 启动，`.\stop.ps1` 停止，`.\run_tests.ps1` 跑测试。

## 功能概要

- 登录与角色（管理员 / 员工），文档公开·内部·机密三级鉴权
- 知识文档归档、分类筛选、全文检索
- 站内问答：权限内分词检索 + 摘要（可选大模型）
- 文档—部门—关键词关系图
- 收藏与审计日志
