# 用例描述：智能问答

| 项 | 内容 |
|----|------|
| 用例名称 | 智能问答 |
| 用例编号 | UC-QA-01 |
| 参与者 | 已登录用户 |
| 前置条件 | 知识库中存在已发布文档；用户已登录 |
| 后置条件 | 生成回答；保存问答历史；写审计 |

## 基本事件流

1. 用户进入智能问答页  
2. 输入自然语言问题并提交  
3. 系统在权限范围内检索相关知识片段  
4. 系统生成回答并展示来源  
5. 用户可点击来源进入文档详情  

## 备选事件流

3a. 无命中片段 → 提示未检索到相关内容  
4a. 已配置大模型 Key → 使用生成式回答；否则本地摘要  

## 业务规则

- 机密知识不得进入无权限用户的检索候选集  
- 回答应尽可能标注来源文档
