# 用户需求说明书

**项目名称**：智慧企业知识财富库系统  
**文档版本**：V1.1  
**日期**：2026-09-15  
**状态**：初稿

---

## 1. 引言

### 1.1 编写目的

定义本系统的用户需求，作为后续系统需求、设计、实现与测试的依据。读者包括：项目组及产品、测试、运维相关干系人。

### 1.2 项目背景

企业内部制度、产品与项目经验分散，检索成本高，难以问答式获取，也缺少知识关联视图。本项目建设轻量可运行的「知识财富库」。

### 1.3 定义与缩略语

| 术语 | 说明 |
|------|------|
| RAG | Retrieval-Augmented Generation，检索增强生成 |
| 知识片段 | 文档切分后的可检索单元（Chunk） |
| 可见性 | public / internal / secret 三级 |

### 1.4 参考资料

- 本项目《竞品调研报告》《系统需求说明书》及 UML 图  
- Flask / SQLAlchemy / ECharts / jieba 等相关技术文档

## 2. 项目概述

### 2.1 产品愿景

帮助企业员工快速查找制度与经验，并通过问答获得带来源的答案，同时理解知识之间的组织关系。

### 2.2 用户角色

| 角色 | 描述 | 典型诉求 |
|------|------|----------|
| 管理员 | 系统运维与内容治理 | 分类、图谱维护、审计、用户查看 |
| 普通员工 | 各部门业务人员 | 查文档、提问、收藏 |
| 部门敏感岗位 | 如信息部 | 访问本部门机密文档 |

### 2.3 运行环境（用户侧）

- 桌面浏览器（Chrome / Edge 近两年版本）  
- 局域网或本机访问 Web 服务  

---

## 3. 业务需求

### BR-01 知识沉淀
员工可将制度、手册、培训资料录入系统并分类管理。

### BR-02 安全可控
不同密级文档对可见范围不同，机密文档按部门隔离。

### BR-03 智能问答
用户可用自然语言提问，系统基于知识库作答并提示来源。

### BR-04 关系洞察
用户可浏览文档与部门、关键词等实体的关联图。

### BR-05 可追溯
关键操作可审计，个人可收藏常用文档。

## 4. 功能需求（用户需求编号）

### 4.1 账户与权限

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| UR-AUTH-01 | 用户可使用用户名密码登录 | 高 |
| UR-AUTH-02 | 用户可退出登录 | 高 |
| UR-AUTH-03 | 系统按角色展示不同菜单 | 高 |
| UR-AUTH-04 | 机密文档仅管理员或同部门用户可访问 | 高 |

### 4.2 知识文档

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| UR-DOC-01 | 用户可浏览其权限范围内的文档列表 | 高 |
| UR-DOC-02 | 用户可按关键词、分类筛选文档 | 高 |
| UR-DOC-03 | 用户可查看文档详情 | 高 |
| UR-DOC-04 | 授权用户可新建/编辑/删除文档 | 高 |
| UR-DOC-05 | 文档支持分类、标签、版本、可见性、状态 | 高 |
| UR-DOC-06 | 管理员可维护分类 | 中 |

### 4.3 智能问答

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| UR-QA-01 | 用户可输入自然语言问题并获得回答 | 高 |
| UR-QA-02 | 回答应展示相关知识来源 | 高 |
| UR-QA-03 | 用户可查看本人历史问答 | 中 |
| UR-QA-04 | 问答仅使用用户有权访问的知识 | 高 |

### 4.4 知识图谱

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| UR-KG-01 | 用户可可视化浏览知识关系图 | 高 |
| UR-KG-02 | 管理员可手工补充节点与关系 | 中 |

### 4.5 收藏与审计

| 编号 | 需求描述 | 优先级 |
|------|----------|--------|
| UR-FAV-01 | 用户可收藏/取消收藏文档 | 中 |
| UR-AUD-01 | 管理员可查看审计日志 | 中 |

## 5. 非功能需求

| 编号 | 类别 | 描述 |
|------|------|------|
| NFR-01 | 可用性 | 核心页面 3 次点击内可达 |
| NFR-02 | 性能 | 演示数据规模下问答响应通常 &lt; 3 秒（本地模式） |
| NFR-03 | 安全 | 密码哈希存储；未登录不可访问业务页 |
| NFR-04 | 可维护 | MVC 分层；提供启停脚本与自动化测试 |
| NFR-05 | 兼容 | 支持 Windows 本地部署 |

---

## 6. 验收标准（用户视角）

1. 能登录并看到工作台统计。  
2. 提问「年假几天」能得到与年休假制度相关的回答及来源。  
3. 图谱页能看到节点连线。  
4. 人事账号无法打开信息部机密文档，信息部账号可以。  
5. 管理员能看到审计记录。
