## 1 项目概述

### 1.1 建设背景

企业制度、手册、项目经验和安全规范通常散落在邮件、即时通讯、个人网盘和部门目录中。员工查找规定需要反复询问，新员工上手成本高；机密材料又容易因链接转发产生跨部门越权。

本项目以“权限可控的知识文档库”为底座，加入可追溯检索问答、知识关系图和审计治理，用完整软件工程过程展示需求、设计、开发、测试和交付能力。

### 1.2 建设目标

| 编号 | 目标 | 成功判据 |
|---|---|---|
| G-01 | 建立统一知识库 | 用户可在权限范围内浏览、检索、查看和维护文档 |
| G-02 | 权限边界可验证 | 部门、密级、作者和发布状态共同决定可见范围，越权返回 403 |
| G-03 | 问答结果可追溯 | 每次回答均展示检索来源，无权限内容不会进入检索范围 |
| G-04 | 知识关系可视化 | 文档、部门、项目、关键词和概念可形成关系图 |
| G-05 | 治理过程可审计 | 登录、文档操作、问答等关键行为可由管理员查询 |
| G-06 | 交付可复现 | 后端测试、前端构建、静态演示和运行说明均可在新环境复现 |

### 1.3 范围边界

**本期包含：**

- 用户登录、退出、会话和管理员/员工角色；
- 文档新建、查看、编辑、删除、分类、标签、版本和状态；
- 公开、内部、机密三级访问控制；
- 关键词检索、分类/部门/密级筛选和分页；
- 本地检索增强问答、来源片段和问答历史；
- 知识关系图浏览及管理员节点/关系维护；
- 工作台统计、收藏、用户目录、分类和审计日志；
- Flask 主系统与 Cloudflare Pages 静态演示。

**本期不包含：**

- 真实企业 SSO、组织架构同步和细粒度 RBAC；
- 真实文件上传解析、版本快照回滚和审核流；
- 向量数据库、混合检索、模型训练或大数据平台；
- 微服务、消息队列、分布式存储和多租户；
- 移动原生应用、跨设备数据同步和真实生产运维承诺。

## 2 用户角色与权限

### 2.1 角色定义

| 角色 | 说明 | 主要能力 |
|---|---|---|
| 匿名访问者 | 未登录用户 | 仅访问登录页、公开元信息、会话探测和健康检查 |
| 员工 | 归属一个部门的普通账号 | 查看权限内文档、检索、问答、收藏、新建文档、维护本人文档 |
| 文档作者 | 文档级身份，不是第三类系统角色 | 作者例外访问本人文档，可编辑或删除本人文档 |
| 管理员 | `admin` 角色 | 拥有员工能力，并可查看全部文档、用户目录和审计日志，维护分类与图谱 |

前端菜单隐藏只用于改善体验，不能替代服务端鉴权。

### 2.2 角色权限矩阵

| 操作 | 匿名 | 员工 | 管理员 |
|---|:---:|:---:|:---:|
| 登录、查看健康检查 | 允许 | 允许 | 允许 |
| 查看工作台、文档、问答、图谱 | 拒绝 | 允许 | 允许 |
| 新建文档 | 拒绝 | 允许 | 允许 |
| 编辑/删除文档 | 拒绝 | 仅本人文档 | 允许 |
| 收藏、查看本人问答历史 | 拒绝 | 允许 | 允许 |
| 查看用户目录 | 拒绝 | 拒绝 | 允许 |
| 筛选和分页查看审计日志 | 拒绝 | 拒绝 | 允许 |
| 维护分类、图谱节点和关系 | 拒绝 | 拒绝 | 允许 |

### 2.3 文档可见性矩阵

| 密级 | 未登录 | 异部门员工 | 同部门员工 | 作者 | 管理员 |
|---|:---:|:---:|:---:|:---:|:---:|
| 公开 `public` | 拒绝 | 允许 | 允许 | 允许 | 允许 |
| 内部 `internal` | 拒绝 | 允许 | 允许 | 允许 | 允许 |
| 机密 `secret` | 拒绝 | 拒绝 | 允许 | 允许 | 允许 |

补充规则：

1. 未发布文档默认不进入普通检索和问答。
2. 作者可访问本人草稿和归档文档。
3. 列表、详情、检索、问答来源和图谱必须复用同一可见性规则。
4. 静态演示站使用本地 Mock 数据，不具备真实服务端鉴权，不得表述为生产权限系统。

## 3 核心业务流程

### 3.1 登录与进入工作台

1. 用户提交用户名和密码。
2. 后端校验密码哈希、登录失败次数和账号状态。
3. 登录成功后建立会话并记录审计日志。
4. 前端读取会话信息，按角色展示导航。
5. 未登录访问业务页时跳转登录页，并限制回跳地址为站内路径。

### 3.2 文档创建、编辑与同步

1. 员工填写标题、正文、摘要、分类、部门、密级、状态、版本和标签。
2. 后端校验必填项、密级、状态和分类。
3. 保存文档后重新切分知识片段并提取关键词。
4. 同步部门、分类、关键词等图谱节点及关系。
5. 文档列表、搜索、问答来源和工作台统计读取新数据。

### 3.3 检索增强问答

1. 后端先按当前用户过滤可见且已发布的文档。
2. 对知识片段执行 jieba 分词、关键词匹配和短语重合评分。
3. 按相关度选取 Top-K 片段，并限制同一文档的片段数量。
4. 有模型配置时调用兼容 OpenAI 协议的服务；失败或无配置时回退本地摘要。
5. 返回回答、模式、来源文档和相关片段，并保存问答历史与审计记录。

### 3.4 知识关系图

1. 文档保存后同步文档、部门、分类和关键词节点。
2. 普通用户只获得本人可见文档及其相邻节点/关系。
3. 管理员可查看完整图谱并新增概念节点或关系。
4. 前端默认展示核心结构，可切换完整标签图谱。

### 3.5 管理与审计

1. 管理员可查看用户目录、文档贡献、角色和部门。
2. 管理员可维护分类和图谱。
3. 审计日志支持操作类型、用户账号、明细关键词、分页和快捷筛选。
4. 失败登录、文档查看与编辑、问答等关键行为均记录审计。

## 4 功能需求

| 编号 | 功能 | 主要说明 | 优先级 | 可验收结果 |
|---|---|---|---|---|
| FR-01 | 登录与会话 | 密码哈希、会话 Cookie、退出失效、站内安全回跳 | P0 | 正确账号可登录，错误账号有提示，退出后业务接口返回 401 |
| FR-02 | 登录防爆破 | 按来源限制连续失败，并记录失败审计 | P0 | 超限后暂时拒绝登录，审计可追溯 |
| FR-03 | 角色与菜单 | 管理员/员工两种角色，前端导航按角色裁剪 | P0 | 非管理员无法进入管理接口，直接访问返回 403 |
| FR-04 | 文档检索 | 标题、摘要、正文、标签检索，分类/部门/密级筛选 | P0 | 关键词返回相关文档，结果按权限过滤并支持分页 |
| FR-05 | 文档管理 | 新建、查看、编辑、删除、收藏、分类、标签、版本和状态 | P0 | 完整流程可用，删除后关联数据和图谱同步清理 |
| FR-06 | 文档密级 | 公开、内部、机密三级访问控制 | P0 | 跨部门访问机密文档返回 403，不泄露标题和正文 |
| FR-07 | 检索增强问答 | 权限过滤、片段评分、Top-K、来源和本地降级 | P0 | 回答有来源；无命中明确说明；外部模型失败可回退 |
| FR-08 | 问答历史 | 保存问题、回答、来源、模式和创建时间 | P1 | 用户只能查看本人历史，历史详情返回结构化来源 |
| FR-09 | 知识图谱 | 节点关系同步、权限过滤、核心/完整视图 | P1 | 图谱可加载、拖拽、缩放；文档节点可进入详情 |
| FR-10 | 图谱维护 | 管理员新增节点和关系 | P1 | 仅管理员可调用维护接口，新增后图谱刷新可见 |
| FR-11 | 工作台 | 文档、收藏、问答、图谱统计和最近动态 | P1 | 统计范围与当前用户权限一致 |
| FR-12 | 用户与分类管理 | 用户目录、文档贡献、分类查看与新增 | P1 | 管理员可用，非管理员被拒绝 |
| FR-13 | 审计日志 | 关键操作记录、服务端筛选和分页 | P0 | 管理员可按类型、用户和明细查询，结果含时间与对象 |
| FR-14 | 运维与演示 | 健康检查、启动脚本、构建脚本和静态演示 | P1 | 健康检查返回正常；前端可构建；静态站可无后端演示 |
| FR-15 | 响应式与可用性 | 加载、空状态、错误提示、移动端适配和无障碍名称 | P1 | 桌面/手机无横向溢出；关键操作有明确状态反馈 |

## 5 数据需求

| 实体 | 关键数据 | 约束与关系 |
|---|---|---|
| 用户 | 用户名、密码哈希、显示名、角色、部门 | 用户名唯一；一个用户可有多篇文档、收藏、问答和审计 |
| 分类 | 名称、说明 | 名称唯一；一篇文档最多属于一个分类 |
| 文档 | 标题、正文、摘要、部门、密级、状态、版本、标签、作者 | 标题和正文必填；关联作者与分类 |
| 知识片段 | 文档、片段序号、正文、关键词 | 多对一关联文档；保存文档时重建 |
| 图谱节点 | 名称、类型、说明、文档关联 | 名称唯一；可关联文档 |
| 图谱关系 | 起点、终点、关系名称 | 多对多连接节点；保存文档时同步 |
| 收藏 | 用户、文档、收藏时间 | 同一用户与文档只允许一条记录 |
| 问答历史 | 用户、问题、回答、来源、模式、时间 | 只向本人展示 |
| 审计日志 | 用户、动作、明细、时间 | 管理员筛选查询，不允许普通用户访问 |

数据质量要求：

- 数据库时间统一使用无时区本地时间格式；
- 演示数据全部为虚构内容；
- 测试使用隔离数据库，不污染 `instance/knowledge.db`；
- API 返回中文标签，不直接暴露内部枚举值；
- 删除文档时同步清理知识片段、收藏和关联图谱对象。

## 6 接口与界面需求

### 6.1 接口约定

- API 前缀统一为 `/api`；
- 请求和响应使用 UTF-8 JSON；
- 业务接口依赖服务端会话 Cookie；
- 未登录返回 401，越权返回 403，资源不存在返回 404，参数错误返回 400；
- 错误结构至少包含 `error` 字段；
- 前端统一处理加载、空数据、错误和重试状态。

### 6.2 页面清单

| 页面 | 核心内容 |
|---|---|
| 登录 | 账号密码、显示/隐藏密码、演示账号、错误提示 |
| 工作台 | 统计卡、部门分布、分类构成、最近文档、问答和审计 |
| 知识文档 | 搜索、热词、筛选、收藏、分页、文档卡片 |
| 文档详情 | 元数据、正文、来源信息、收藏、复制、编辑和删除 |
| 文档编辑 | 正文大编辑区、预览、元数据、未保存提醒、保存快捷键 |
| 智能问答 | 问题输入、建议问题、来源片段、历史折叠和对话 |
| 知识关系图 | 核心/完整视图、节点聚焦、拖拽缩放、管理员维护 |
| 用户管理 | 账号目录、角色、部门、贡献和搜索 |
| 审计日志 | 快捷筛选、条件查询、分页和移动端卡片展示 |
| 关于系统 | 版本、能力、技术栈、场景和交付说明 |

## 7 非功能需求

| 类别 | 要求 |
|---|---|
| 安全 | 密钥仅在服务端环境变量；前端和静态站不得包含真实密钥；密码不得明文保存或返回 |
| 权限 | 服务端统一判定；列表、详情、检索、问答与图谱口径一致 |
| 性能 | 常规课程数据量下页面可快速响应；前端按页面拆分路由资源 |
| 可靠性 | 外部模型失败时回退本地摘要；测试和演示数据库隔离 |
| 可用性 | 关键操作有加载、成功、空状态和错误反馈；危险操作需要确认 |
| 兼容性 | 支持现代 Chromium 浏览器和常见桌面/移动分辨率 |
| 可维护性 | 前后端分离，服务、路由、模型和 API 客户端职责清晰 |
| 可测试性 | 核心权限、CRUD、RAG、图谱和审计路径可自动化执行 |
| 可访问性 | 表单有标签或无障碍名称，按钮有可理解文本，焦点可见，弹窗可用 Esc 关闭 |

## 8 异常处理与降级

| 场景 | 预期处理 |
|---|---|
| 用户名或密码错误 | 返回明确提示，记录失败审计，不泄露账号是否存在 |
| 连续登录失败 | 触发临时限流，提示稍后重试 |
| 跨部门访问机密文档 | 返回 403，不返回正文、摘要或片段 |
| 文档不存在 | 返回 404，并给出返回列表入口 |
| 标题或正文为空 | 前端阻止提交，后端再次校验 |
| 问答无命中 | 明确说明当前权限范围内没有足够依据，不伪造答案 |
| 大模型超时或未配置 | 回退本地检索摘要，并标注回答模式 |
| 图谱数据为空 | 显示空状态，不展示错误图表 |
| 网络请求失败 | 页面保留可操作状态，并允许刷新或重试 |
| 编辑页未保存离开 | 浏览器内路由和关闭/刷新时提示确认 |

## 10 验收结论

系统应完成“登录 → 检索/查看 → 提问并核对来源 → 浏览图谱 → 管理员审计”的完整业务链路。验收以冻结版本的实际测试日志、构建结果、页面检查和文件清单为准，不以文档中的预期描述替代实际运行结果。
