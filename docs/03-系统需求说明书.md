# 系统需求说明书

**项目名称**：智慧企业知识财富库系统  
**文档版本**：V1.1  
**日期**：2026-09-15

---

## 1. 引言

本文档将用户需求转化为可设计、可实现、可测试的系统需求，编号前缀 `SR`。

## 2. 系统总体描述

### 2.1 软件架构

采用 **B/S + Flask MVC**：

- Model：SQLAlchemy 实体  
- View：Jinja2 模板  
- Controller：Blueprints  

### 2.2 逻辑模块

1. 认证授权模块  
2. 知识文档模块  
3. RAG 问答模块  
4. 知识图谱模块  
5. 收藏审计模块  
6. 系统运维模块（健康检查、关于页、启停）

### 2.3 数据存储

- SQLite：`instance/knowledge.db`  
- 可选附件目录：`uploads/`

---

## 3. 功能需求（系统）

### 3.1 认证授权

| 编号 | 系统需求 | 对应用户需求 |
|------|----------|--------------|
| SR-AUTH-01 | 系统应校验用户名密码，失败提示错误 | UR-AUTH-01 |
| SR-AUTH-02 | 系统应使用会话维持登录态 | UR-AUTH-01 |
| SR-AUTH-03 | 系统应按 role=admin/employee 控制管理菜单 | UR-AUTH-03 |
| SR-AUTH-04 | 文档访问判定：admin 全过；secret 需同部门或作者 | UR-AUTH-04 |

### 3.2 知识文档

| 编号 | 系统需求 | 对应用户需求 |
|------|----------|--------------|
| SR-DOC-01 | 列表仅返回当前用户可访问且 published 文档（管理编辑另行授权） | UR-DOC-01 |
| SR-DOC-02 | 支持 q、category_id 过滤 | UR-DOC-02 |
| SR-DOC-03 | 保存文档后自动切分写入 knowledge_chunks | UR-DOC-04 |
| SR-DOC-04 | 保存文档后同步 graph 节点与边 | UR-KG-01 |
| SR-DOC-05 | 支持 visibility、status、version、tags 字段 | UR-DOC-05 |

### 3.3 RAG 问答

| 编号 | 系统需求 | 对应用户需求 |
|------|----------|--------------|
| SR-QA-01 | 对问题分词，在权限内 chunk 中评分取 Top-K | UR-QA-01/04 |
| SR-QA-02 | 无 API Key 时输出本地摘要答案 | UR-QA-01 |
| SR-QA-03 | 有 API Key 时调用 Chat Completions，上下文为命中片段 | UR-QA-01 |
| SR-QA-04 | 持久化 QAHistory（问题、答案、来源、模式） | UR-QA-03 |

### 3.4 知识图谱

| 编号 | 系统需求 | 对应用户需求 |
|------|----------|--------------|
| SR-KG-01 | 提供 /graph/data JSON（nodes/links） | UR-KG-01 |
| SR-KG-02 | 前端力导向图渲染 | UR-KG-01 |
| SR-KG-03 | 管理员可新增节点/边 | UR-KG-02 |

### 3.5 收藏审计

| 编号 | 系统需求 | 对应用户需求 |
|------|----------|--------------|
| SR-FAV-01 | favorites 唯一约束 (user_id, document_id) | UR-FAV-01 |
| SR-AUD-01 | 登录、查看、问答、增删改写入 audit_logs | UR-AUD-01 |

### 3.6 运维

| 编号 | 系统需求 |
|------|----------|
| SR-OPS-01 | /health 返回应用版本与数据库连通性 |
| SR-OPS-02 | 提供 start/stop 脚本与自动化测试入口 |

## 4. 接口需求（主要页面路由）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET/POST | /auth/login | 登录 |
| GET | /auth/logout | 退出 |
| GET | /dashboard | 工作台 |
| GET | /knowledge/ | 文档列表 |
| POST | /knowledge/create | 新建 |
| GET | /qa/ | 问答 |
| GET | /graph/ | 图谱页 |
| GET | /graph/data | 图谱数据 |
| GET | /health | 健康检查 |
| GET | /about | 关于系统 |
