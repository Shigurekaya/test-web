# UML 图目录说明

本目录为 **PlantUML** 源文件，覆盖本系统的用例图、时序图、活动图、状态图、类图、部署图、构件图，并补充 ER 图与三层架构图。

## 文件列表

| 文件 | 图类型 |
|------|--------|
| `01-用例图.puml` | 用例图 |
| `02-登录时序图.puml` | 时序图 |
| `03-RAG问答时序图.puml` | 时序图 |
| `04-文档发布活动图.puml` | 活动图（含水道） |
| `05-文档状态图.puml` | 状态图 |
| `06-类图.puml` | 类图 |
| `07-ER图.puml` | E-R 图 |
| `08-部署图.puml` | 部署图 |
| `09-构件图.puml` | 构件图 |
| `10-三层架构.puml` | 架构说明图 |

## 如何渲染

1. 打开 [PlantText](https://www.planttext.com/)  
2. 粘贴对应 `.puml` 内容  
3. 导出 PNG/SVG，插入设计文档  

也可使用 VS Code PlantUML 插件或 ProcessOn 导入。

## 建议阅读顺序

用例 → 登录时序 → RAG 时序 → 活动 → 状态 → 类图 → ER → 三层架构 → 构件 → 部署
