# 用例描述：管理知识文档

| 项 | 内容 |
|----|------|
| 用例名称 | 管理知识文档 |
| 用例编号 | UC-DOC-01 |
| 参与者 | 已登录用户（编辑需作者或管理员） |
| 前置条件 | 用户已登录 |
| 后置条件 | 文档持久化；索引与图谱已同步 |

## 基本事件流（新建）

1. 用户进入新建文档页  
2. 填写标题、正文、可见性等并提交  
3. 系统保存文档  
4. 系统自动切分知识片段  
5. 系统同步知识图谱关系  
6. 跳转详情页供确认  

## 备选事件流

2a. 标题或正文为空 → 提示错误不保存  
编辑/删除：仅作者或管理员可操作
