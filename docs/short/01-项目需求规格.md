# 智慧企业知识财富库系统——项目需求规格（精简版）

| 项目 | 内容 |
|---|---|
| 项目名称 | 智慧企业知识财富库系统 |
| 技术形态 | Vue 3 前端 + Flask REST API + SQLite 数据库 |

## 1. 项目目标

建设一个面向企业内部制度、手册和业务知识的数据库应用系统，实现文档统一管理、按部门与密级授权、全文检索、可溯源智能问答、知识关系图和审计治理。

系统以**数据库应用为核心**，融合轻量 RAG 智能问答、知识图谱和数据可视化等新技术，不将普通统计分析夸大为大数据平台。

## 2. 用户角色

| 角色 | 主要权限 |
|---|---|
| 普通员工 | 登录、检索和查看有权文档、收藏、问答、查看本人历史 |
| 部门员工 | 在普通员工权限基础上访问本部门机密文档 |
| 管理员 | 用户与文档全局管理、图谱维护、审计日志查询 |

## 3. 功能需求

| 编号 | 需求 | 主要说明 | 验收标准 |
|---|---|---|---|
| FR-01 | 认证与权限 | 登录、退出、密码哈希、失败限流、管理员/员工角色控制 | 未登录不能访问业务页；越权请求返回 403 |
| FR-02 | 文档管理 | 新建、查看、编辑、删除、分类、标签、版本、状态管理 | 管理流程可用，修改后检索和图谱同步更新 |
| FR-03 | 密级控制 | 公开、内部、机密三级；机密仅同部门或作者可见 | 跨部门用户无法查看机密正文及片段 |
| FR-04 | 知识检索 | 按标题、摘要、正文、标签检索，支持分类、部门、密级筛选和分页 | 关键词能返回相关文档并按权限过滤 |
| FR-05 | 智能问答 | 文档切分、关键词检索、Top-K 排序、来源展示；可选大模型增强 | 回答附来源；模型失败时回退本地摘要 |
| FR-06 | 知识图谱 | 文档、部门、分类、关键词关系展示及管理员维护 | 节点和边可查询、可维护、按权限裁剪 |
| FR-07 | 工作台 | 文档、收藏、问答、图谱统计及最近动态 | 统计范围与当前用户权限一致 |
| FR-08 | 审计管理 | 记录登录、文档、问答等关键操作，支持筛选与分页 | 管理员可追溯关键操作 |
| FR-09 | 静态演示 | Cloudflare Pages 展示主要页面和交互 | 无需后端即可演示，且不得包含真实密钥 |

## 4. 非功能需求

| 类别 | 要求 |
|---|---|
| 安全 | 密钥仅保存在服务端环境变量；前端和静态站不得包含真实密钥 |
| 可用性 | 关键页面提供加载、空状态、错误提示和移动端适配 |
| 一致性 | 文档修改后，知识片段、标签、图谱和统计数据保持同步 |
| 可维护性 | 前后端分离，服务层与 API 分层，配置通过环境变量管理 |
| 兼容性 | 支持现代 Chromium 浏览器和常见桌面/移动分辨率 |
| 质量 | 自动化测试覆盖权限、CRUD、RAG、图谱和审计核心流程 |

## 5. 新技术定位

- **数据库应用**：真实实现，使用 SQLAlchemy + SQLite，是系统主体。
- **AI 应用**：实现轻量 RAG；配置兼容 OpenAI 协议的服务后可调用大模型，未配置时使用本地检索摘要。
- **数据分析**：使用 ECharts 展示文档分布、分类构成和问答统计，属于业务数据可视化。
- **知识图谱**：使用关系表存储节点和关系，由 ECharts 进行网络可视化，不是独立图数据库。
- **大数据**：当前未采用 Hadoop、Spark、Flink、Kafka、数据仓库或分布式存储，不应宣称已建设大数据平台。

## 6. 范围边界

包含：文档库、权限、检索、问答、图谱、工作台、审计、用户管理和静态演示。

不包含：真实企业身份系统、跨组织协作、海量数据处理、模型训练、移动原生应用、独立微服务集群。

## 7. 验收结论

系统应能够完成“登录→检索/查看→提问→查看来源→审计”的完整业务链路；核心自动化测试全部通过，前后端可独立构建并部署，且仓库和静态页面中不出现真实 API 密钥。

## 8. 后续功能需求

以下功能不属于当前已交付范围，按用户价值和实现成本分批推进。

| 优先级 | 功能 | 用户价值 | 验收标准 |
|---|---|---|---|
| P0 | 附件上传与解析 | 支持 PDF、DOCX、Markdown、TXT 入库并自动切分 | 附件继承文档权限，可下载原文并参与检索 |
| P0 | 文档版本与回滚 | 保留每次发布版本，降低误改和误删风险 | 可查看历史版本、差异并恢复指定版本 |
| P0 | 混合检索 | 关键词检索结合语义向量与重排，提高问法变化下的召回率 | 无精确关键词时仍能返回语义相关结果 |
| P0 | 问答反馈与引用跳转 | 用户可评价回答并直接打开引用文档 | 反馈入库，来源标题可跳转详情 |
| P1 | 知识运营看板 | 展示热搜词、零结果搜索、未解决问题和高频引用文档 | 管理员可按时间范围查看趋势并定位内容缺口 |
| P1 | 订阅与通知 | 用户可订阅文档、分类或部门更新 | 新文档和新版本可生成站内提醒 |
| P1 | 审核发布与纠错 | 支持草稿、审核、发布和用户纠错反馈 | 发布状态可追踪，纠错有处理闭环 |
| P2 | 批量导入与导出 | 支持模板导入、批量校验和结果导出 | 导入失败可定位到行级错误，导出遵循权限 |
| P2 | 评论与协作 | 围绕文档开展评论、补充和责任人处理 | 评论与审计关联，权限清晰 |
| P2 | 企业身份与开放接口 | 接入 SSO、细粒度角色、Webhook/Open API | 外部系统可按授权安全集成 |

## 9. 后续非功能目标

- 检索链路增加索引、缓存和性能监控，避免每次请求全量扫描知识片段。
- 引入数据库迁移机制，确保表结构升级可追踪、可回滚。
- 增加 CSRF 防护、细粒度权限、备份恢复和审计留存策略。
- 前端按页面拆分大型依赖，完善无障碍、错误恢复和弱网体验。
- 建立 AI 问答评测集，持续衡量召回率、引用准确率和无答案识别能力。
