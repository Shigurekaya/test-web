# 智慧企业知识财富库系统——项目需求规格（精简版）

| 项目 | 内容 |
|---|---|
| 适用系统 | 智慧企业知识财富库系统 V2.0 |
| 技术基线 | Vue 3 + Vite、Flask 3 REST API、SQLAlchemy、SQLite、ECharts、jieba、pytest |

## 1 项目概述

企业制度、手册、项目经验和安全规范常分散在邮件、即时通讯、个人网盘和部门目录中，查找成本高，机密材料也容易因链接转发而越权。

本项目以权限可控的知识文档库为底座，提供文档管理、检索问答、知识关系图和审计治理，用于课程中的完整软件工程实践。

建设目标：

| 编号 | 目标 | 成功判据 |
|---|---|---|
| G-01 | 统一知识库 | 用户可在权限范围内浏览、检索、查看和维护文档 |
| G-02 | 权限可验证 | 部门、密级、作者和发布状态共同决定可见范围 |
| G-03 | 问答可追溯 | 回答展示来源，无权限内容不进入检索范围 |
| G-04 | 关系可视化 | 文档、部门、项目、关键词和概念可形成关系图 |
| G-05 | 治理可审计 | 登录、文档操作和问答等关键行为可查询 |
| G-06 | 交付可复现 | 测试、构建、静态演示和运行说明可重复执行 |

## 2 范围边界

**本期包含：**

- 登录、退出、会话和管理员/员工角色；
- 文档 CRUD、分类、标签、版本和发布状态；
- 公开、内部、机密三级访问控制；
- 关键词检索、筛选和分页；
- 本地检索增强问答、来源和问答历史；
- 知识关系图浏览与管理员维护；
- 工作台、收藏、用户目录、分类和审计；
- Flask 主系统与 Cloudflare Pages 静态演示。

**本期不包含：**

- 真实 SSO、组织架构同步和细粒度 RBAC；
- 附件解析、版本快照回滚和审核流；
- 向量数据库、混合检索、模型训练和大数据平台；
- 微服务、消息队列、分布式存储和多租户；
- 移动原生应用、跨设备同步和生产级运维承诺。

## 3 用户角色与权限

| 角色 | 说明 | 主要能力 |
|---|---|---|
| 匿名访问者 | 未登录用户 | 仅访问登录页、公开元信息、会话探测和健康检查 |
| 员工 | 归属一个部门的普通账号 | 查看权限内文档、检索、问答、收藏、新建文档、维护本人文档 |
| 文档作者 | 文档级身份，不是独立角色 | 可访问、编辑或删除本人文档 |
| 管理员 | `admin` 角色 | 拥有员工能力，可查看全部文档、用户目录和审计日志，维护分类与图谱 |

前端菜单隐藏只用于改善体验，不能替代服务端鉴权。

### 3.1 角色权限

| 操作 | 匿名 | 员工 | 管理员 |
|---|:---:|:---:|:---:|
| 登录、健康检查 | 允许 | 允许 | 允许 |
| 工作台、文档、问答、图谱 | 拒绝 | 允许 | 允许 |
| 新建文档 | 拒绝 | 允许 | 允许 |
| 编辑/删除文档 | 拒绝 | 仅本人文档 | 允许 |
| 收藏、本人问答历史 | 拒绝 | 允许 | 允许 |
| 用户目录、审计日志 | 拒绝 | 拒绝 | 允许 |
| 分类、图谱维护 | 拒绝 | 拒绝 | 允许 |

### 3.2 文档可见性

| 密级 | 未登录 | 异部门员工 | 同部门员工 | 作者 | 管理员 |
|---|:---:|:---:|:---:|:---:|:---:|
| 公开 `public` | 拒绝 | 允许 | 允许 | 允许 | 允许 |
| 内部 `internal` | 拒绝 | 允许 | 允许 | 允许 | 允许 |
| 机密 `secret` | 拒绝 | 拒绝 | 允许 | 允许 | 允许 |

补充规则：

1. 未发布文档默认不进入普通检索和问答。
2. 作者可访问本人草稿和归档文档。
3. 列表、详情、检索、问答来源和图谱复用同一可见性规则。
4. 静态演示使用本地 Mock 数据，不具备真实服务端鉴权。

## 4 功能需求

| 编号 | 功能 | 主要说明 | 可验收结果 |
|---|---|---|---|
| FR-01 | 登录与会话 | 密码哈希、会话 Cookie、退出失效、站内安全回跳 | 正确账号可登录，退出后业务接口返回 401 |
| FR-02 | 登录防爆破 | 连续失败限制并记录失败审计 | 超限后暂时拒绝登录，审计可追溯 |
| FR-03 | 角色与菜单 | 管理员/员工两种角色，前端导航按角色裁剪 | 非管理员访问管理接口返回 403 |
| FR-04 | 文档检索 | 标题、摘要、正文、标签检索及分类/部门/密级筛选 | 结果按权限过滤并支持分页 |
| FR-05 | 文档管理 | 新建、查看、编辑、删除、收藏、分类、标签、版本和状态 | 流程可用，删除后关联数据同步清理 |
| FR-06 | 文档密级 | 公开、内部、机密三级访问控制 | 跨部门访问机密文档返回 403，不泄露内容 |
| FR-07 | 检索增强问答 | 权限过滤、片段评分、Top-K、来源和本地降级 | 回答有来源；无命中明确说明；模型失败可回退 |
| FR-08 | 问答历史 | 保存问题、回答、来源、模式和创建时间 | 用户只能查看本人历史 |
| FR-09 | 知识图谱 | 节点关系同步、权限过滤、核心/完整视图 | 图谱可加载、拖拽、缩放并进入文档详情 |
| FR-10 | 图谱维护 | 管理员新增节点和关系 | 仅管理员可调用，新增后可见 |
| FR-11 | 工作台 | 文档、收藏、问答、图谱统计和最近动态 | 统计范围与当前用户权限一致 |
| FR-12 | 用户与分类管理 | 用户目录、贡献统计、分类查看与新增 | 管理员可用，非管理员被拒绝 |
| FR-13 | 审计日志 | 关键操作记录、服务端筛选和分页 | 可按类型、用户和明细查询 |
| FR-14 | 运维与演示 | 健康检查、启动脚本、构建脚本和静态演示 | 健康检查正常，前端可构建，静态站可演示 |
| FR-15 | 响应式与可用性 | 加载、空状态、错误提示、移动端适配和无障碍名称 | 桌面和手机无横向溢出，关键操作反馈明确 |

## 5 数据与接口要求

| 实体 | 关键数据 | 约束 |
|---|---|---|
| 用户 | 用户名、密码哈希、显示名、角色、部门 | 用户名唯一 |
| 分类 | 名称、说明 | 名称唯一 |
| 文档 | 标题、正文、摘要、部门、密级、状态、版本、标签、作者 | 标题和正文必填 |
| 知识片段 | 文档、序号、正文、关键词 | 保存文档时重建 |
| 图谱节点/关系 | 名称、类型、起点、终点、关系名称 | 名称唯一，保存文档时同步 |
| 收藏 | 用户、文档、时间 | 同一用户与文档唯一 |
| 问答历史 | 用户、问题、回答、来源、模式、时间 | 仅本人可见 |
| 审计日志 | 用户、动作、明细、时间 | 仅管理员可查询 |

接口约定：

- API 前缀统一为 `/api`，请求和响应使用 UTF-8 JSON；
- 业务接口依赖服务端会话 Cookie；
- 未登录返回 401，越权返回 403，资源不存在返回 404，参数错误返回 400；
- 错误响应至少包含 `error` 字段；
- 测试使用隔离数据库，不污染演示库。

## 6 非功能与异常要求

| 类别 | 要求 |
|---|---|
| 安全 | 密钥仅在服务端环境变量；密码不明文保存或返回 |
| 权限 | 服务端统一判定，列表、详情、检索、问答与图谱口径一致 |
| 性能 | 常规课程数据量下快速响应，前端按路由拆分资源 |
| 可靠性 | 外部模型失败回退本地摘要，测试和演示数据库隔离 |
| 可用性 | 关键操作有加载、成功、空状态和错误反馈；危险操作需确认 |
| 兼容性 | 支持现代 Chromium 浏览器和常见桌面/移动分辨率 |
| 可维护性 | 前后端分离，服务、路由、模型和 API 客户端职责清晰 |
| 可访问性 | 表单有无障碍名称，按钮文本明确，焦点可见，弹窗可用 Esc 关闭 |

| 场景 | 处理方式 |
|---|---|
| 用户名或密码错误 | 明确提示并记录失败审计，不泄露账号是否存在 |
| 连续登录失败 | 触发临时限流，提示稍后重试 |
| 跨部门访问机密文档 | 返回 403，不返回正文、摘要或片段 |
| 文档不存在 | 返回 404，并提供返回列表入口 |
| 标题或正文为空 | 前端阻止提交，后端再次校验 |
| 问答无命中 | 说明当前权限范围内没有足够依据，不伪造答案 |
| 模型超时或未配置 | 回退本地检索摘要，并标注模式 |
| 图谱数据为空 | 显示空状态，不展示错误图表 |
| 编辑页未保存离开 | 路由切换和关闭/刷新时提示确认 |

## 7 验收

| 需求组 | 验证内容 |
|---|---|
| 认证与权限 | 登录、退出、限流、越权访问和管理员隔离 |
| 文档与密级 | CRUD、收藏、分页、跨部门机密访问 |
| RAG 问答 | 来源、无命中、历史权限和模型降级 |
| 知识图谱 | 权限过滤、核心/完整视图、文档跳转和管理员维护 |
| 审计与管理 | 筛选、分页、用户目录和分类维护 |
| 系统与构建 | 健康检查、pytest、前端构建、移动端和静态演示 |

验收基线：

- pytest 全部通过，以实际日志为准；
- Ruff 检查通过；
- 前端生产依赖审计无已知漏洞；
- 桌面和手机宽度下无页面级横向溢出；
- 浏览器控制台无未处理错误；
- 静态演示资源可访问，部署不包含真实密钥。

系统应完成“登录 → 检索/查看 → 提问并核对来源 → 浏览图谱 → 管理员审计”的完整链路。验收以冻结版本的实际运行结果为准。
