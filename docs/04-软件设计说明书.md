# 软件设计说明书

**项目名称**：智慧企业知识财富库系统  
**文档版本**：V1.0  
**日期**：2026-09-15

---

## 1. 设计目标

交付可运行、可演示、可测试的知识财富库，突出 RAG 与知识图谱，结构符合 Flask MVC。

## 2. 总体架构（三层）

```
┌─────────────────────────────────────────┐
│ 表现层  Jinja2 + Bootstrap + ECharts     │
├─────────────────────────────────────────┤
│ 业务层  Blueprints + services(RAG/Graph)│
├─────────────────────────────────────────┤
│ 数据层  SQLAlchemy ORM + SQLite          │
└─────────────────────────────────────────┘
```

对应 UML：`docs/uml/07-三层架构说明.puml`、`08-部署图.puml`、`09-构件图.puml`

## 3. 模块设计

| 模块 | 职责 | 主要文件 |
|------|------|----------|
| auth | 登录退出 | blueprints/auth.py |
| main | 工作台/关于/健康检查 | blueprints/main.py |
| knowledge | 文档 CRUD、分类、收藏 | blueprints/knowledge.py |
| qa | 问答与历史 | blueprints/qa.py |
| graph | 图谱展示与维护 | blueprints/graph.py |
| admin | 用户与审计 | blueprints/admin.py |
| rag service | 切分、检索、生成 | services/rag.py |
| graph service | 节点边同步 | services/graph.py |

## 4. RAG 设计

1. **切分**：段落优先，超长滑动窗口（400/50）  
2. **索引**：chunk + jieba 关键词  
3. **检索**：分词重合打分，关键词命中加权 1.5  
4. **生成**：本地摘要 或 OpenAI 兼容 API  
5. **权限**：先过滤可访问 document_id，再检索 chunk  

## 5. 知识图谱设计

- 节点类型：document / department / project / keyword / concept  
- 文档保存触发 `sync_document_graph`  
- 前端 ECharts force graph  

## 6. 权限设计

```
can_view(user, doc):
  if admin: allow
  if doc.visibility == secret:
      allow iff same department or author
  else: allow (public/internal for logged-in users)
```

## 7. 数据库设计要点

- documents.status: draft / published / archived  
- documents.visibility: public / internal / secret  
- favorites 唯一约束防重复收藏  
- qa_history.sources 存 JSON 字符串  

ER / 类图见 `docs/uml/05-类图.puml`、`06-ER图.puml`

## 8. 界面设计原则

- 工作台集中展示关键指标与入口  
- 登录页说明产品价值与演示账号  
- 问答页同时展示答案与命中证据卡  
- 错误页 403/404/500 统一风格  

## 9. 运行与部署设计

开发默认：本机 `127.0.0.1:5000`，`start.ps1` 后台拉起。  
可扩展部署：Nginx → Gunicorn → Flask → SQLite/PostgreSQL（部署图中给出演进示意）。
