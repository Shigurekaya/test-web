# 智慧企业知识财富库系统——项目开发计划


## 1. 项目目标

完成一个可运行、可演示、可测试的企业知识管理数据库应用，打通文档权限、检索、RAG 问答、知识图谱、审计和前端展示，并形成完整交付材料。

## 2. 阶段计划

| 阶段 | 主要工作 | 阶段产物 | 退出条件 |
|---|---|---|---|
| S1 启动与需求 | 场景调研、角色与用例、范围确认、非功能需求 | 需求规格、用例清单 | 需求范围和验收标准确认 |
| S2 系统设计 | 架构、数据模型、接口、权限规则、页面原型 | 设计说明、ER 图、接口清单 | 设计基线通过审查 |
| S3 核心功能开发 | 登录、用户、文档 CRUD、分类、收藏、权限、审计 | 可运行核心系统 | 核心业务闭环可演示 |
| S4 新技术集成 | 文档切分、检索、RAG、模型接入、图谱、图表 | 问答、图谱和工作台 | AI 与图谱链路可验证 |
| S5 测试与优化 | 权限矩阵、异常分支、自动化测试、构建与适配 | 测试报告、缺陷修复记录 | 质量门禁全部通过 |
| S6 交付与答辩 | 文档定稿、截图、演示数据、部署、答辩材料 | 文档、报告、演示站 | 交付包完整可复现 |

## 3. 关键里程碑

| 里程碑 | 完成标志 |
|---|---|
| M1 需求基线 | 角色、功能范围、验收标准确认，不再随意扩张 |
| M2 设计基线 | 数据表、接口、权限规则和核心流程可落地 |
| M3 核心闭环 | 登录、文档、权限、审计完整可演示 |
| M4 智能能力 | RAG 问答可显示来源，图谱与统计正常 |
| M5 质量门禁 | 自动化测试、前端构建和权限检查全部通过 |
| M6 最终交付 | 代码、文档、截图、报告和静态演示齐全 |
| M7 检索与基础升级 | 迁移、全文与向量检索、反馈、安全和可观测性达标 |
| M8 知识运营闭环 | 附件、版本、审核、订阅、纠错和运营分析可演示 |
| M9 扩展与规模化 | 批量导入导出、开放接口和外部集成形成闭环 |

## 4. 交付物清单

- 可运行源代码与生产构建
- 需求规格、系统设计、开发计划、测试计划
- 测试用例、测试报告和验收记录
- UML、页面截图和演示数据
- Cloudflare Pages 静态展示站
- 最终课程报告与答辩材料

## 5. 质量与测试计划

| 类型 | 检查内容 |
|---|---|
| 单元/接口测试 | 认证、CRUD、检索、问答、图谱、审计、权限矩阵 |
| 安全测试 | 越权访问、未发布文档、开放重定向、登录限流、密钥泄露 |
| 前端测试 | 路由守卫、空状态、错误提示、响应式布局、控制台错误 |
| 构建验收 | `pytest`、`npm run build`、`npm run pages:build` |
| 演示验收 | Flask 主系统与 Cloudflare Pages 均可正常登录和浏览 |

完成标准：核心自动化测试全部通过；被禁止的跨部门机密访问返回 403；前端无横向溢出；源码和静态站不包含真实密钥。

## 6. 风险与应对

| 风险 | 影响 | 应对 |
|---|---|---|
| 需求范围过大 | 无法按期完成 | 以文档—权限—问答—审计为主线，其他功能降级 |
| 大模型接口不稳定 | 问答失败 | 保留本地检索摘要回退，记录失败原因 |
| 密钥误入前端 | 严重泄露 | 只使用服务端环境变量；静态站通过 Function 代理 |
| 权限过滤遗漏 | 机密数据泄露 | 检索前先过滤文档，接口测试覆盖跨部门场景 |
| 文档与代码不一致 | 答辩被质疑 | 以代码和测试结果为准，文档明确边界与限制 |
| 后期集中写文档 | 交付仓促 | 每阶段同步更新文档和截图，最后只做统稿 |

## 7. 后续优化阶段

| 阶段 | 主要工作 | 阶段产物 | 退出条件 |
|---|---|---|---|
| S7 检索与基础升级 | Alembic 迁移、PostgreSQL 适配、全文与向量索引、混合检索、重排、缓存、CSRF、日志指标、问答反馈与引用跳转 | 可持续迭代的检索增强版 | 检索指标、性能与安全检查通过 |
| S8 知识运营闭环 | 附件解析、版本快照与回滚、审核发布、纠错反馈、订阅通知、运营看板 | 知识运营增强版 | 文档生命周期和运营反馈闭环可演示 |
| S9 扩展与规模化 | 批量导入导出、评论协作、SSO、细粒度 RBAC、Webhook/Open API、容量与备份演练 | 可集成扩展版本 | 外部集成、权限和恢复演练通过 |

### 7.1 优先级原则

1. 先解决权限、数据迁移、检索性能和安全合规问题。
2. 再补齐附件、版本、审核、反馈等知识运营能力。
3. 最后补齐批量导入、协作、企业身份、外部集成和规模化能力。
4. 每个阶段必须同步补充测试、文档、截图和回归验证。
