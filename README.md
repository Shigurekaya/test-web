## 选题与卖点

- 选题：智慧企业知识财富库系统（**RAG / 知识图谱**）
- 技术：Python + Flask MVC + SQLite + jieba + ECharts
- 能力：分级知识文档 · 权限贯穿的轻量 RAG 问答 · 知识图谱 · 收藏审计
