# 用例描述

按 UML 用例图（[`../uml/01-用例图.puml`](../uml/01-用例图.puml)）拆出的详细用例。
每个用例给出参与者、前置/后置条件、基本事件流、备选事件流、业务规则与特殊需求，
并与需求编号（UR / SR）和对应 UML 图建立双向关联。

| 用例 | 编号 | 参与者 | 关联 UML |
|------|------|--------|----------|
| [登录系统](./UC-登录.md) | UC-AUTH-01 | 管理员、普通员工 | 登录时序图 |
| [管理知识文档](./UC-管理知识文档.md) | UC-DOC-01 | 管理员、文档作者 | 文档发布活动图、文档状态图 |
| [智能问答](./UC-智能问答.md) | UC-QA-01 | 已登录用户 | RAG 问答时序图 |

## 编号约定

| 前缀 | 含义 |
|------|------|
| `UC-AUTH-nn` | 认证与授权 |
| `UC-DOC-nn` | 知识文档 |
| `UC-QA-nn` | 站内问答 |
| `UC-KG-nn` | 知识图谱 |
| `UC-FAV-nn` | 收藏 |
| `UC-AUD-nn` | 审计 |
| `UC-OPS-nn` | 系统运维 |

## 与用例图的对应关系

用例图中共 11 个用例点：登录、退出、管理知识文档、检索知识文档、智能问答、
浏览知识图谱、收藏文档、维护分类、维护图谱关系、查看审计日志、查看用户列表。
其中「管理知识文档」「智能问答」以 `<<include>>` 方式依赖「检索知识文档」——
因为两者内部都要先做检索（文档保存后建索引、问答前先圈定权限内候选集），
这一点在上表的用例描述中体现为「权限过滤先于检索打分」。

其余用例点（退出、浏览图谱、收藏、维护分类、维护图谱关系、查看审计与用户列表）
功能边界清晰、步骤单一，未单独成文；其验收由
[`../05-测试报告.md`](../05-测试报告.md) 中的自动化用例覆盖。
